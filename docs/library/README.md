# Library

Reference samples and templates for OpenCode extensions. This directory stores
working examples for use as source material when building the app's analyzer
and maker features.

Do not mix these samples with the `.opencode/` directory — `.opencode/` holds
the active project configuration.

## Subdirectories

| Dir | Purpose |
| --- | ------- |
| `skills/` | Sample SKILL.md files |
| `commands/` | Sample slash command markdowns |
| `tools/` | Sample custom tool definitions |
| `mcp/` | Sample MCP server configs |
| `agents/` | Sample agent markdown/JSON configs |
| `examples/` | Larger end-to-end examples and config dumps |
