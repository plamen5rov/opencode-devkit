# .opencode

Active project configuration for OpenCode. Files here are loaded at runtime
and affect how OpenCode behaves in this project.

Contrast with `docs/library/` — those are reference samples and templates, not
active configuration.

## Subdirectories

| Dir | Purpose |
| --- | ------- |
| `agents/` | Project-specific agent definitions (`.md` or `.json`) |
| `commands/` | Project-specific slash commands (`.md`) |
| `skills/` | Project-specific skills (`SKILL.md` files) |
